# ホーム画面仕様書

## 画面遷移フロー

```
セットアップ完了
  → ホーム（初回）
  → 質問画面
  → パラメータ表示 + タスク表示
  → ホーム（2回目以降）

2日目以降:
  → ホーム（2回目以降）
  → 質問画面
  → パラメータ表示 + タスク表示
```

---

## 状態管理

AsyncStorageから以下を読み取って表示を切り替える。

| キー | 型 | 説明 |
|------|-----|------|
| `hasLaunched` | boolean | セットアップ完了済みか |
| `hasDiagnosedEver` | boolean | 一度でも診断したか |
| `lastDiagnosedDate` | string | 最後に診断した日付（YYYY-MM-DD） |
| `allTasksCompleted` | boolean | 今日のタスクを全完了したか |
| `userName` | string | ユーザー名 |

---

## 状態パターン

### 1. 初回（セットアップ直後・未診断）
- 挨拶: `[ユーザー名]さん、はじめまして。 ⚙️`
- フッターナビゲーション: **ホームのみ有効**（他はタップ不可・グレーアウト）
- SYSTEM ANALYSISカード: 表示
- 発射ボタン: 大きいボタン表示
- 分析サマリー: **非表示**
- 行動サマリー: **非表示**
- ボタン下テキスト: 「はじめての診断をしてみましょう」

### 2. 2回目以降・未診断
- 挨拶: `[ユーザー名]さん、おかえりなさい。 ⚙️`
- フッターナビゲーション: **全て有効**
- SYSTEM ANALYSISカード: 表示
- 発射ボタン: 大きいボタン表示
- 分析サマリー: **非表示**（未診断時は「今日の質問に答えよう！」を表示）
- 行動サマリー: **非表示**（未診断時は「本日未診断」を表示）

### 3. 2回目以降・診断済み
- 挨拶: `[ユーザー名]さん、おかえりなさい。 ⚙️`
- フッターナビゲーション: **全て有効**
- SYSTEM ANALYSISカード: 表示
- 発射ボタン: 「本日診断済み ✓」に切り替わり（タップ不可）
- 分析サマリー: **表示**
- 行動サマリー: **表示**

### 4. タスク全完了時
- 行動サマリーの表示が「今日のタスク完了 ✓」に切り替わり
- 診断前は非表示のまま

## SYSTEM ANALYSISカード

```
■ SYSTEM ANALYSIS
日々の質問に答えることで、あなたの状態を可視化します。
```

全状態で表示。

---

## 発射ボタン（メインアクション）

```
診断前:
  大きい発射ボタン 🚀
  タップ → ローディングアニメーション → 質問画面へ

診断済み:
  「本日診断済み ✓」表示（タップ不可）
```

---

## 分析サマリーカード（診断済み時のみ表示）

```
ANALYSIS
[dominant metric名]  [値]   ← dominant metricのみ大きく表示
                            ← 他4指標は分析画面に任せる
▼ 詳細を見る               ← 右下に小さく（分析画面へ遷移）
```

- 表示するのは**dominant metric（最も高い指標）1つのみ**
- 他4指標は分析画面に任せる

---

## 行動サマリーカード（診断済み時のみ表示）

```
TASKS
今日のタスク  2/3       ← 残り枚数
残り  18:32             ← バフ有効カウントダウン
▼ 詳細を見る            ← 右下に小さく（行動画面へ遷移）
```

- 未診断時: 「本日未診断」表示
- タスク全完了時: 「今日のタスク完了 ✓」に切り替わり（診断前は非表示）

## コンポーネント構成

```
app/(tabs)/index.tsx          ← 画面本体（状態判定・出し分け）
components/home/
  GreetingHeader.tsx          ← 挨拶 + ⚙️アイコン
  SystemAnalysisCard.tsx      ← SYSTEM ANALYSISカード
  LaunchButton.tsx            ← 発射ボタン / 診断済み表示
  AnalysisSummaryCard.tsx     ← 分析サマリー
  ActionSummaryCard.tsx       ← 行動サマリー
```

---

## 実装メモ

- 状態判定は `app/(tabs)/index.tsx` の `useEffect` でAsyncStorageから読み取る
- `lastDiagnosedDate` と今日の日付を比較して `hasDiagnosedToday` を判定
- フッターの無効化は `tabBarButton: () => null` または `tabBarStyle` で制御
- 初回フラグは質問終了後に `hasDiagnosedEver: true` をAsyncStorageに保存
